# Integrated Dynamics Create Compat

**A compatibility mod for Create and Integrated Dynamics.**

Integrated Dynamics Create Compat addresses compatibility issues between Create and Integrated Dynamics in Minecraft 1.20.1, with a focus on cable network cleanup and Wand of Symmetry functionality.

## Features

- **Cable Network Cleanup:** Improves Integrated Dynamics cable network cleanup when cables are moved by Create, helping prevent network glitches and game crashes.
- **Wand of Symmetry Compatibility:** Adds symmetry functionality for Integrated Dynamics cables when using Create's Wand of Symmetry.

## Requirements

- Minecraft 1.20.1
- Minecraft Forge
- Create
- Integrated Dynamics

Make sure to install the appropriate versions of each dependency for Minecraft 1.20.1.

## Development Status

**Beta — Minecraft 1.20.1**

This mod is in beta. Compatibility and behavior may change in future versions. Testing with different mod configurations is encouraged.
